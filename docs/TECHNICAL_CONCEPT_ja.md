# 技術的な構想：都市エコ脈動水インフラ（UEPWI）

[English Version](TECHNICAL_CONCEPT.md)

> このリポジトリは、概念的な提案と理論的なフレームワークを示すものです。UEPWIが実証済みのシステムであるとも、都市のヒートアイランド、粉塵、花粉の問題を確実に解決できるとも主張しません。現実世界での実装の前に、科学的なモデリング、パイロット試験、公衆衛生の評価、インフラの審査、ガバナンスの設計が必要です。

## 1. 概念的フレームワークの導入

**都市エコ脈動水インフラ（Urban Eco-Pulsing Water Infrastructure：UEPWI）**は、都市環境の中に、局所的な水文学的循環を回復させることを提案する、理論的なフレームワークです。不透水面が広がり、雨水が速やかに排水される現代の都市は、浸透と蒸発という自然のプロセスを、ほぼ失っています。

UEPWIは、制御された周期的な水の流れを人為的に再び導入することで、都市に一定の「代謝」機能を回復させ、相互に関連するいくつかの環境ストレスを同時に緩和できるかもしれない、と仮定します。

**ステータス：**この文書は、仮説、提案するメカニズム、理論上のパイロット設計を概説します。広範な実証的検証を必要とする、概念モデルです。

```text
       |

       |

+---------------------------------------------------+

       |
       v
[Evaporation (Cooling)] / [Ground Infiltration] / [Runoff (Recapture)]
```

（図の凡例：大気・天候 →（降雨）→ 都市の集水面 →（捕集）→ 地下貯水槽 ←（処理済みの中水／管理された河川取水）→（実現可能な場合は太陽光発電によるポンプ）→ 多段階のろ過・滅菌（重要な安全上の結節点）→ 配水網 → 対象を絞った適用（街路・歩道へのミスト噴霧／中央分離帯・樹木への灌漑／花粉捕捉のためのミスト噴霧）→ 蒸発（冷却）／地中への浸透／流出水（再捕集））

## 3. サブシステムの詳細な説明

理論上のUEPWIのシステムは、緊密に統合された複数のサブシステムから成ります。

### 3.1. 水の調達と貯留

- **主な水源：**雨水の流出水を捕集・貯留するように設計された、大規模な地下貯水槽。これは二つの目的を果たします。システムのための水源の確保と、豪雨の際の都市の洪水リスクの緩和です。
- **副次的な水源：**乾燥期の運用を確保するために、システムは処理済みの家庭の中水を統合するかもしれません。特定の地理的な文脈では、生態学的な流量の要件が厳格に維持されることを条件に、地域の水路からの慎重に管理された取水が検討されるかもしれません。

### 3.2. ろ過と滅菌（重要な結節点）

公共空間で水をエアロゾル化する前に、*レジオネラ・ニューモフィラ*のような水を介した病原体の伝播を防ぐため、厳格な多段階の処理を通さなければなりません。

- **機械的なろ過：**物理的なごみ、浮遊物、粒子の除去。
- **化学的・生物学的な安全性：**継続的な紫外線処理、場合によっては塩素処理、リアルタイムの水質監視。
- **運用上の要件：**公共のミスト噴霧の処理基準は、エアロゾル化した水滴を吸い込む可能性があるため、通常の灌漑よりも厳格でなければなりません。

### 3.3. 配水・適用ネットワーク

- **低流量の配管：**中央分離帯、歩道、街灯、道路脇の構造物といった、既存のインフラに統合されたネットワーク。
- **対象を絞ったノズル：**目的に応じて、異なる種類のノズルを用いるかもしれません。気化冷却と花粉の捕捉には超微細なミスト、粉塵の抑制には対象を絞った散水、植生にはドリップ灌漑です。
- **歩行者の快適性：**システムは、歩行者に直接水を吹きかけてはならず、不快感、滑りやすい路面、視界の問題を最小限にするよう設計されなければなりません。

### 3.4. 制御、監視、エネルギー

- **センサー網：**気温、表面温度、湿度、土壌水分、PM2.5、PM10、可能であれば花粉の数を測るセンサーの配置。
- **制御アルゴリズム：**リアルタイムのデータに基づいて特定の区域を作動させる知的なシステム。たとえば、表面温度がしきい値を超えたときや、花粉のピーク時間帯にのみ、ミスト噴霧を作動させます。
- **再生可能エネルギー：**都市の構造に統合された太陽光発電（PV）パネルが、ポンプとセンサーに電力を供給し、より低炭素な運用と、運用に伴う排出の削減を目指すかもしれません。

## 4. 提案する作用のメカニズム

UEPWIのフレームワークは、この統合されたシステムが、次の効果をもたらしうると仮定します。

### 4.1. 気化冷却による熱の緩和

**仮説：**加熱された都市の表面に制御して水を与えると蒸発が起こり、潜熱を吸収して、表面と周囲の気温を下げ、ヒートアイランドの緩和に貢献する。

水の相変化には、大きなエネルギーが必要です。乾いて熱くなった表面に水を与えることで、このエネルギーの一部を、周囲の環境から奪えるかもしれません。

### 4.2. 粒子状物質（粉塵）の抑制

**仮説：**定期的なミスト噴霧と路面の湿潤化は、空気中の粒子状物質を物理的に捕捉し、沈降した粉塵の再浮遊を防ぐかもしれない。

微細な水滴は、浮遊するPM10やPM2.5と衝突して質量を増やし、沈降させることができます。湿った路面は、粘着力も高め、車両の通行や風による再浮遊を減らすかもしれません。

### 4.3. 空気中のアレルゲン（花粉）の低減

**仮説：**ミスト噴霧のシステムは、都市部の空気中の花粉濃度を下げられるかもしれない。

花粉の粒は、水滴に捕捉されて地面に洗い落とされ、理論上は、その周辺のアレルゲンの負荷を減らします。これは、現地での測定を必要とする仮説のままです。

### 4.4. 生態学的な強化

**仮説：**都市のグリーンインフラに、一貫して最適化された水の供給を行うと、植物の健康が改善し、自然の蒸散率が高まるかもしれない。

健全な植生は、自然の日陰と気化冷却を提供し、人工的なミスト噴霧の取り組みを支え、地域の生態学的なレジリエンスを高めます。

## 5. 提案するパイロット試験の設計

概念から検証へ進むには、厳密で小規模なパイロット試験が必要です。

### 5.1. 場所と規模

管理された都市の一区画、たとえば100メートルの一街区や、指定された広場に、UEPWIのシステムの局所的な版を備えることができます。構造的に似た隣接する街区を、システムを設置しない対照地点とすべきです。

### 5.2. データ収集の計画

運用期間中は、たとえば5分間隔で、連続的にデータを記録すべきです。データは安全に保管し、試験地点と対照地点の間で比較分析すべきです。

### 5.3. 測定可能な指標

パイロットでは、次を定量的に測定すべきです。

- **熱：**表面温度、周囲の気温、相対湿度。
- **大気の質：**PM2.5、PM10、測定が可能であれば、局所的な花粉の数。
- **資源の使用：**水の総消費量とエネルギーの消費量。
- **間接的な指標：**冷房度日（CDD）の推定削減量、植生の健康、保守の頻度。

### 5.4. 評価基準

パイロットは、次を示せれば、有望と見なされます。

1. 暑さ指数（WBGT）を危険なゾーンに押し上げることなく、対照地点と比べて、表面温度または周囲の気温が統計的に有意に低下する。
2. システムの運用中に、局所的な粒子状物質または花粉の数が、測定可能な形で減少する。
3. 定期的な水質のサンプリングで、水を介した病原体が検出されない。
4. 実現可能な場合には、統合された再生可能エネルギーによって、エネルギーの使用が大幅に相殺される。
5. 道路の安全上の危険、歩行者の不快感、インフラの劣化が増えない。

### 5.5. 監視すべき失敗モード

- **システムの故障：**ポンプの故障、ノズルの詰まり、停電、センサーの誤作動。
- **水質の劣化：**紫外線処理や塩素処理の失敗による、病原体の増殖。
- **過加湿：**冷却効果ではなく、湿っぽく不快な微気候の発生。
- **冬季の危険：**パージのプロトコルの失敗による、配管の凍結や路面の凍結。
- **社会的受容の失敗：**水しぶきへの曝露、騒音、水の無駄遣いという認識、保守による混乱に関する苦情。

## 6. 世界の気候戦略との関係

UEPWIは、CO₂削減の代替ではありません。CO₂削減は引き続き必要です。UEPWIは、補完的な都市の適応・緩和支援の構想として位置づけられています。

都市の周囲の気温を下げられる可能性により、このシステムは、冷房度日と、それに続くエアコンのエネルギー需要を減らせるかもしれません。この局所的なエネルギー消費の削減は、より広いCO₂削減の目標と整合しうりますが、それに取って代わるものではありません。
